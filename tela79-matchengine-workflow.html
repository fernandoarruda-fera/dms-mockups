Regras de Match Engine

cadastro · core

Vincula automaticamente um input (email, documento, evento API) a exatamente 1 workflow — garante CONCEPT-WORKFLOW-OBLIGATORY. Resultado é único e determinístico: 1 match = vincula, 0 = órfão, >1 = bloqueio + alerta crítico. Concept: CONCEPT-MATCH-ENGINE.
