Biblioteca de SOPs

v2 · DP #31-A

SOP é um container de Stages — agrupa procedimentos passo-a-passo. Workflows arrastam SOPs como blocos; os stages vêm dentro. Editar uma SOP em uso versiona a SOP inteira (v_n permanece nos workflows antigos).

SOPs em uso são imutáveis. Editar uma SOP referenciada por workflows ativos forka uma nova versão (v_n → v_(n+1)). A v_n original continua viva nos workflows que já a usavam, garantindo execuções históricas reprodutíveis. Use Versionar para evoluir; use Arquivar só quando nenhum workflow ativo depender da SOP.
